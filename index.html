X Cleaner

Block noisy AI reply bots and blocked-account clutter on x.com/twitter.com.

Install (Chrome / Edge)

  1. Download ZIP and unzip it locally.
  2. Open chrome://extensions (or edge://extensions).
  3. Enable Developer mode.
  4. Click Load unpacked and select the unzipped folder.
